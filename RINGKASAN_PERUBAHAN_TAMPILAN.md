# Ringkasan Perubahan Tampilan AntreCukur

Perubahan ini merapikan istilah yang tampil kepada pengguna agar AntreCukur terasa seperti aplikasi pengelolaan barbershop, bukan halaman tugas praktikum.

## Istilah pada aplikasi

| Sebelumnya | Sekarang |
|---|---|
| Tugas Demo Modul 3 | Tim kapster |
| Demo Modul 3 · Tim Kapster & API | Lihat daftar kapster |
| Latihan Modul 2 | Preferensi & bantuan |
| Codelab 1 · Dark Mode | Pratinjau tampilan |
| Codelab 2 · Dokumentasi | Panduan penggunaan |
| Kelola data antrean | Pengaturan antrean |
| Mulai antrean kosong | Mulai hari baru |
| Muat data contoh | Isi antrean dengan data contoh (di bagian Pemeriksaan aplikasi) |
| Tes Promise berhasil/gagal | Uji proses berhasil/gagal (di bagian Pemeriksaan aplikasi) |

## Materi praktikum tetap tersedia

- External API dan Interface tetap diterapkan pada layanan profil kapster.
- Custom dan Pre-built Async Function tetap digunakan untuk memuat serta memperbarui profil.
- `new Promise()`, `resolve()`, `reject()`, `.then()`, `.catch()`, dan `.finally()` tetap diterapkan pada pemeriksaan ketersediaan dan kontrol pemeriksaan aplikasi.
- `useContext` tetap digunakan pada pratinjau tampilan.
- Navigasi Stack dan catch-all route tetap digunakan pada panduan penggunaan.

Istilah akademis tetap ada di kode dan panduan praktikum untuk membantu penjelasan kepada asisten laboratorium, tetapi tidak ditampilkan sebagai judul fitur kepada pengguna aplikasi.

## Transparansi data

Foto dan informasi rambut pada halaman Tim Kapster merupakan profil referensi dari layanan data publik, bukan data pegawai atau bukti keahlian profesional yang diverifikasi. Nama operasional kapster dan status antrean dikelola oleh aplikasi. Pemeriksaan Promise adalah simulasi sisi aplikasi, bukan pemesanan online ke server.
